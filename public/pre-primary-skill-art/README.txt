Pre-primary holistic grid — custom skill pictures
=================================================

Put ONE image per skill here. Filename MUST match the database skill_key (lowercase, underscores).

  public/pre-primary-skill-art/{skill_key}.webp   (preferred — smaller PDFs)
  or .png / .jpg / .jpeg   (tried in that order if .webp is missing)

Keep files light: aim for ~120–250 px on the longest side, compressed (so reports/PDFs stay small).

Default skill_key names (15):
  relating_with_others
  games
  helping
  naming
  cleanliness
  caring_for_the_environment
  taking_care_of_myself
  toilet_habits
  body_hygiene
  reciting_numbers
  counting_concepts
  addition_concepts
  drawing
  reading
  writing

If a file is missing, the report uses the built-in SVG for that skill until you add the image.
